# EasyFace format findings

The initial `RW5.fprj` was 124-byte UTF-8 XML, not a binary container. Its SHA-256 is `74D99BD25793E8E3FE816DA41A6121037BE5473DB60D2D123F1E30E6A95233E5`. That initial version is preserved as `RW5.original.fprj`. It has `FaceProject DeviceType="465"` and one empty `Screen` (`Title`, `Bitmap`).

After EasyFace saved the project, `RW5.fprj` became 337 bytes, SHA-256 `CA8B67CFE463FFC4D36CCF3076B2E23508B5B1A78ABAAEBB7DCDDD30DE0C4C4E`. A byte-identical copy is `samples/widgets.fprj`. The new child is `<Widget Shape="32" Name="NumberDisplay" X="179" Y="167" Width="54" Height="126" Alpha="255" Digits="1" Alignment="0" Spacing="0" Blanking="0" Visible_Src="0" Value_Src="811" BitmapList="" />`. The local device database names Shape 32 `DigitalNumImage` and source `0811` Hour (24-hour value 0–23). The leading zero is dropped when serialized to numeric string `811`. `BitmapList` is empty, and there were no project image files to copy. The widget's data binding is real, while digit rendering in this sample cannot work without images.

The local Gen2 v4.23 bundle is at `C:\Users\galas\Downloads\EasyFace_Gen2_CompilerV423`. `Compiler.exe` reports product version 4.23.0.0. Its `DeviceInfo.db` is XML despite the `.db` extension. The entry for device 465 is explicitly `Redmi Watch 5`, width 432, height 514, rounded rectangle radius 80. Entries 3651 and 3652 are Active and Lite respectively. The database lists `DigitalNumImage`, `ImageList`, `Image`, and source data for hour, minute, second, day, month, week, steps and battery.

The open [Mi Create `.fprj` parser](https://github.com/ooflet/Mi-Create/blob/main/src/utils/project.py) confirms that `BitmapList` for Shape 32 is a `|`-separated sequence of digit image filenames. Its canvas requires at least 10 images (0–9), and projects use an `images` directory next to the `.fprj`. Its `Screen.Bitmap` is a thumbnail property; an actual static image uses Shape 30 with `Bitmap`. `output/SchoolFace.fprj` is generated from the preserved initial project plus cloned Shape 32 widgets, Shape 30 image widgets, and generated digit sprites. The source IDs for minute, second, date, steps, and battery come from local device 465 data. These copied widgets have not been visually verified in EasyFace or on hardware.

The public EasyFace GitHub repository contains a README and wiki, but no editor or compiler source code in its root. Mi Create's [compiler wrapper](https://github.com/ooflet/Mi-Create/blob/main/src/utils/project.py) provides a `-b` invocation. The local Gen2 v4.23 `Compiler.exe` accepted the generated project and produced `SchoolFace.face` with `No Errors`. Compiler acceptance does not establish correct display or safe installation on a physical watch.

Sources: [EasyFace repository](https://github.com/m0tral/EasyFace), [EasyFace functions wiki](https://github.com/m0tral/EasyFace/wiki/EasyfacefuncRU), [DigitalNumbers wiki](https://github.com/m0tral/EasyFace/wiki/DigitalNumbersRU), local `DeviceInfo.db`.
